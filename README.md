# خوانا

«خوانا» یک ابزار سبک برای مطالعهٔ درست متن‌های فارسی و ترکیبی راست‌به‌چپ است.
تمام پردازش‌ها داخل مرورگر انجام می‌شوند و متن واردشده به سرور ارسال یا ذخیره
نمی‌شود.

## امکانات

- نمایش صحیح متن‌های ترکیبی فارسی، انگلیسی، عدد و کد
- پشتیبانی سبک و امن از Markdown
- تنظیم اندازهٔ نوشته و حالت روشن/تیره
- چسباندن از کلیپ‌بورد، متن نمونه، پاک‌کردن و کپی
- رابط واکنش‌گرا برای موبایل و دسکتاپ
- بستهٔ آمادهٔ Docker و Nginx

## اجرای سریع با Docker

روی سرور، داخل پوشهٔ پروژه اجرا کنید:

```bash
docker compose up -d --build
```

سپس سایت از طریق پورت `80` و آدرس IP سرور در دسترس است:

```text
http://SERVER_IP
```

برای متوقف‌کردن سرویس:

```bash
docker compose down
```

## اجرای محلی برای توسعه

نیازمندی: Node.js نسخهٔ 22 یا جدیدتر.

```bash
npm ci
npm run dev
```

نسخهٔ تولید:

```bash
npm run build
npm run start
```

## دامنه و HTTPS

فایل `nginx.conf` برای پراکسی‌کردن برنامه آماده است. برای استفادهٔ عمومی بهتر
است دامنه را به IP سرور متصل و HTTPS را در لایهٔ بیرونی، مانند Cloudflare یا
یک reverse proxy دارای گواهی Let's Encrypt، فعال کنید.

## حریم خصوصی

این نسخه دیتابیس، حساب کاربری، analytics و ذخیره‌سازی مرورگر ندارد. با بستن یا
بارگذاری مجدد صفحه، متن پاک می‌شود.
