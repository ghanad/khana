# خوانا

«خوانا» یک ابزار سبک برای مطالعهٔ درست متن‌های فارسی و ترکیبی راست‌به‌چپ است.
تمام پردازش‌ها داخل مرورگر انجام می‌شوند و متن واردشده به سرور ارسال یا ذخیره
نمی‌شود.

## امکانات

- نمایش صحیح متن‌های ترکیبی فارسی، انگلیسی، عدد و کد
- پشتیبانی سبک و امن از Markdown: تیتر، فهرست، نقل‌قول، کد و جدول
- جهت‌یابی درست هر پاراگراف بر پایهٔ استاندارد Unicode
- تنظیم اندازهٔ نوشته و حالت روشن/تیره
- تنظیم فاصلهٔ خطوط، عرض متن، فاصلهٔ پاراگراف و قلم
- حالت مطالعهٔ بدون حواس‌پرتی با میان‌برهای صفحه‌کلید
- چسباندن از کلیپ‌بورد، متن نمونه، پاک‌کردن و کپی
- بازیابی متن و تنظیمات شما در همان مرورگر
- رابط واکنش‌گرا برای موبایل و دسکتاپ
- بستهٔ آمادهٔ Docker و Nginx

## اجرای سریع با Docker

روی سرور، داخل پوشهٔ پروژه اجرا کنید:

```bash
docker compose up -d --build
```

سپس سایت از طریق پورت `80` و آدرس IP سرور در دسترس است:

```text
http://SERVER_IP
```

برای متوقف‌کردن سرویس:

```bash
docker compose down
```

## اجرای محلی برای توسعه

نیازمندی: Node.js نسخهٔ 22 یا جدیدتر.

```bash
npm ci
npm run dev
```

نسخهٔ تولید:

```bash
npm run build
npm run start
```

## دامنه و HTTPS

فایل `nginx.conf` برای پراکسی‌کردن برنامه آماده است. برای استفادهٔ عمومی بهتر
است دامنه را به IP سرور متصل و HTTPS را در لایهٔ بیرونی، مانند Cloudflare یا
یک reverse proxy دارای گواهی Let's Encrypt، فعال کنید.

## میان‌برهای صفحه‌کلید

| کلید | کار |
| --- | --- |
| `Cmd/Ctrl` + `+` | بزرگ‌تر کردن متن |
| `Cmd/Ctrl` + `-` | کوچک‌تر کردن متن |
| `f` یا `ب` | روشن و خاموش کردن حالت مطالعه |
| `Esc` | خروج از حالت مطالعه |

## حریم خصوصی

متن واردشده فقط در `localStorage` همان مرورگر ذخیره می‌شود و به هیچ سروری
فرستاده نمی‌شود. با زدن دکمهٔ «پاک‌کردن» متن از حافظهٔ مرورگر هم حذف می‌شود.
این نسخه دیتابیس، حساب کاربری و analytics ندارد. اگر می‌خواهید هیچ چیز ذخیره
نشود، دکمهٔ پاک‌کردن را بزنید یا از حالت ناشناس مرورگر استفاده کنید.
